What changed since the Aug-2 audit — the good news

The Aug-2 verdict was "three good products that never met." That gap is closed in code: the session pipeline (start → per-user synthesis → proposal → approve → re-validate at live price → execute → per-position monitor) is genuinely wired into the one production entrypoint, with per-session LLM billing feeding a fail-closed cap. The Rust engine ships inside the production Docker image. Confirmed bugs #1–4 from the old audit (quota bypass, admin fail-open, unfed risk tracker, Delta crash) are fixed with traced call paths.

Why users see a dead product anyway

  • None of the 43 commits is deployed — Render suspended the workspace before they could ship.

The free-cap math (50 users × free tier)

One 30-min session ≈ 40–70 requests / 0.7–1.3M tokens ($0 on :free). OpenRouter free caps ≈ 50 req/day — or ~1,000 req/day after a one-time $10 credit (verify current terms). 50 users staggered across the day ≈ 3,400 req/day = dead key. Clustered into hot windows ≈ 560 req/day = it fits. The hot-window mechanic isn't just UX — it is the cost model.

Ordered cost levers

  • Buy the one-time $10 OpenRouter credit — 20× the request cap; still effectively $0/mo
  • Shrink the 40k-token analysis prompt to a few k (pulse summary in, raw JSON out)
  • Fix the symbol mismatch — recovers ~1/3 of spend instantly (env one-liner)
  • Hot-window clustering — sessions share the demand-gated analysis cycles
  • Wire the strategy cache (built, unwired) + keep analysis cache ≥2 cycles
  • Global daily request counter, fail-closed — nothing tracks requests today; a dead-primary rotation day multiplies the 40k prompt by every retry
  • Honest floor at scale: ~$10–20/mo of paid inference once >10–15 staggered sessions/day — a Lite-tier pricing input, not a launch cost

AUDIT / QUANT DESK — WHAT THE EVIDENCE ALLOWS

Quant verdict: a real filter, no directional edge, log everything

Validated — build on it

  • Tradability = a NOW-cast filter for move size over the next ~4–12h (IC +0.083/+0.096 at 4×1h bars; survives vol-normalization; decays to nothing by 24 bars).
  • Hour-of-day is the strongest factor (residual IC +0.093, t +7.07) and is deterministic from the clock — the only honestly forward piece. London–NY overlap ≈ 17:30–20:30 IST: perfect copy for Indian evening users.
  • Intraday is the only honest channel: scalp fails validation (weights flip at 12 bars) and TDS economics; swing IC is insignificant at 24 bars, negative at 72.

Refuted / unproven — never claim

  • Regime→direction is dead (walk-forward ΔIC −0.008, a coin flip). The engine enforces this on the wire; the ban must now travel up the stack — the LLM synthesis layer is the only source of direction and carries zero empirical validation. Mirror the Rust contract test in the frontend.
  • No variant shows skill after multiple-testing correction (deflated Sharpe 0.00 everywhere); no costs/slippage/funding modeled; 2 of 6 factors unmeasured.
  • Therefore: real-money launch is indefensible. Paper-first is not caution — it's the only position the data permits.

Day-one logging (falsifiability)

  • pulse_snapshots writer on every publish — full factor JSON + reference price (zero writers today; everything downstream is blocked on this).
  • Forward-return backfill (15m/1h/4h + MFE/MAE) → re-run the walk-forward at +6 weeks; if temporal IC dies, the badge comes down.
  • Per-proposal log: pulse id → channel → LLM direction → user decision → paper outcome — builds the direction-layer evidence that doesn't exist.
  • Hour-of-day |return| buckets per symbol → replaces the hand-set liquidity map with learned hot hours.

The honest product sentence

"CryptAI ships a validated market-conditions filter with live public calibration, per-user trade construction, and unmetered position protection — on paper desks first, with real money gated behind six weeks of live evidence and a compliance floor." Design consequence: intraday holds (4–12h) outlive 30-minute sessions — the monitor isn't a feature, it's the product's spine.
