# PRODUCT.md — CryptAI

## Register
Hybrid. The landing/auth surfaces are **brand** (design IS the product: convert a
skeptical retail trader into a signup). The dashboard is **product** (design
SERVES the work: monitoring live trading, dense numbers, fast scanning).

## Platform
web

## What it is
A multi-agent AI crypto-trading system. Five specialist agents (data, analysis,
memory, strategy, risk) run a pipeline over BTC, ETH and Gold; every AI-drafted
setup must clear a deterministic risk gate before an order exists. Users start
on paper trading, may connect exchange keys (testnet-gated, non-custodial), and
choose Off / Paper / Manual / Auto modes.

## Users
Retail crypto traders (India-first, global-ready) burned by hype bots; they
distrust "AI trading" marketing. Secondary: technical friends/reviewers judging
craft. Currency display toggles $ / ₹ (default $; landing is $-only).

## Purpose & desired outcome
Visitor believes: "this is a disciplined system, not a hype bot" → signs up →
reaches paper trading. In-app: user trusts what the agents are doing because
everything is observable and honest (empty states explain *why*).

## Positioning (one line)
Most bots are one model with an API key; CryptAI is a desk — specialists that
argue, a gate that decides.

## Brand personality
Terminal-grade restraint. Disciplined, honest, quietly confident. Institutional
vocabulary ("desk", "gate", "pipeline") without suit-and-tie stiffness. The
voice never inflates: real enforced numbers only, "Illustrative" labels on
mockups, "most cycles, nothing clears the gate" as a boast.

## Anti-references (never look like)
- Generic AI-SaaS: purple/indigo gradients, gradient text, glassmorphism-by-default,
  rounded-2xl card grids, icon-chip feature cards, eyebrow labels on every
  section, numbered-section scaffolding, fake metrics ($2.4B), particle fields,
  3D-tilt fake-browser mockups, hover scale-pops, button shine sweeps.
- Crypto-bro maximalism: neon, gold coins, rocket emojis, dark-web green terminals.

## Conversion & proof
Primary CTA: "Start paper trading" (signup, no credit card). Proof style:
honesty over social proof — enforced risk limits shown as a spec sheet, the
live product itself as the hero background, no fabricated testimonials.

## Accessibility
- prefers-reduced-motion honored everywhere (typed headline, demo loops, pulses).
- Body contrast ≥ 4.5:1 on dark; semantic profit/loss color never the only signal.
- aria-labels on icon buttons; typed/animated text keeps full accessible names.

## Strategic design principles
1. Identity is crimson-on-black + Geist + Instrument Serif italic accents — evolve
   expression, never these tokens.
2. One accent moment per screen; hairlines and spacing carry structure, not glow.
3. Every section gets its OWN structure (manifesto / spec sheet / dots / strip);
   repeating one layout grammar is the failure mode.
4. Numbers shown must be real and enforced in code.
5. Motion is choreographed per element (ease-out expo, 150–300ms UI), never a
   uniform fade-up reflex.
